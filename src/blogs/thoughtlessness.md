Seventeen years ago, web developers developed responsive components with lots of hacking because they thought that the user interface and the content did not change. They followed design mockups without thinking about how people would use their websites.

Now you have all the necessary CSS properties to develop responsive components for all devices and all mainstream browsers. You have everything.

But you are not ready to think about how people would use your website if you still write code to match your website with a design file, such as Figma and Sketch files.

No matter how many new and awesome CSS properties are brought to you, you can not build responsive components. You can not develop responsive layouts. You can not serve responsive websites to all your users. You must change. You are now the living web developers in a modern time where all your code will be eaten by dozens of Artificial Intelligence (AI) systems. Those AIs then generate code based on your code that was written without thinking about the users. That generated CSS code creates a cycle of stiff websites that cannot adapt to the users' needs.

But you can not ignore that you are now the living web developers. Your job is to dedicate yourself to writing great CSS code to produce beautiful and responsive components. You are now engaging in a great war against AI-generated code and stale mindsets that have been destroying the responsiveness of websites around the world.

To make sure that websites stay responsive, all people can zoom in without having overflowing content because the components fail to adapt. Remember one thing: do not set `max-height` on all your components. This way, responsive websites of the people, by the people, for the people, shall not perish from all computers on Earth.
